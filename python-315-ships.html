Вышел Python 3.15: ленивые импорты, UTF-8 по умолчанию и заметный JIT

12.10.2026 · по материалам первоисточника
Python Foundation выпустила 3.15.0 — крупнейший релиз за последние годы: 5643 коммита от 1012 авторов. Ленивые импорты ускоряют запуск, UTF-8 стал кодировкой по умолчанию, а экспериментальный JIT наконец даёт реальные проценты скорости.

Python 3.15.0 вышел 9 октября 2026 года, и это самый насыщенный релиз за много лет: 5643 коммита от 1012 контрибьюторов. Для нашего канала важно, что это обновление «кухни» всего ИИ-стека — на Python живут PyTorch, LangChain и почти все агентские фреймворки, так что ускорение старта и рантайма почувствуют все.

Ленивый старт вместо тяжёлого импорта

Главная бытовая фича — PEP 810: явные ленивые импорты. Модуль подгружается только при первом реальном обращении, а не в момент запуска скрипта. Для ИИ-приложений, где импорт torch или transformers съедает секунды и гигабайты памяти до первой строчки кода, это прямой выигрыш в холодном старте. В комплекте — PEP 829 с конфигурационными файлами старта пакета и новый профайлер Tachyon с высокой частотой сэмплирования (PEP 799).

UTF-8 как норма

Python наконец перестал оглядываться на наследие Windows: кодировкой по умолчанию стал UTF-8 (PEP 686). Больше не нужно помнить про cp1251 и cp932 при чтении файлов и работе со stdin — кириллица, иероглифы и эмодзи обрабатываются одинаково на любой ОС. Для русскоязычных разработчиков это, пожалуй, самый приятный пункт релиза.

JIT набирает силу и новые типы

Экспериментальный JIT-компилятор, который в 3.13 был скорее заделом, в 3.15 даёт измеримый результат: +7–8% (геометрическое среднее) на x86-64 Linux и +11–12% на AArch64 macOS против обычного интерпретатора. В язык добавлены встроенные типы sentinel (PEP 661) и frozendict (PEP 814), распаковка в comprehensions (PEP 798), а фрейм-указатели теперь включены по умолчанию — профилировщики и трейсеры видят стек без пересборки интерпретатора. Официальные сборки macOS теперь устанавливают поддержку free-threading по умолчанию.

Обновляться стоит осторожно: 3.15 требует пересборки нативных расширений под новый стабильный ABI, а на macOS 27.0 есть известный баг с tkinter. Полный список изменений — в справочном разделе «What's new in Python 3.15».
