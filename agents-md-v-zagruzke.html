Markdown — новый исполняемый файл: ИИ-агентов угнали через AGENTS.md в папке «Загрузки»

26.10.2026 · по материалам первоисточника
Исследователи Forever Security поймали живую атаку: скачанный с сайта файл AGENTS.md заставил кодинг-агента устанавливать вредоносный npm-пакет. Codex подчинился в 90% случаев, а Claude Code потерял OAuth-токен. «Чинить здесь нечего», — вздыхают эксперты.

Как это работает

Сотрудники Forever Security — компании, которая мониторит риски ИИ-агентов — обнаружили на компьютере клиента попытку установить вредоносный npm-пакет `function-color`. След привёл к файлу AGENTS.md в папке `~/Downloads`, которая заодно служила рабочей директорией агента. Кодинг-агенты (Claude Code, OpenAI Codex, Cursor CLI) автоматически читают инструктивные Markdown-файлы из рабочей папки — и послушно выполняют то, что в них написано. «Здесь нечего патчить: агент, следующий AGENTS.md из своей папки, делает ровно то, для чего создан», — отмечают исследователи.

Тихая выгрузка из браузера

Проблема в том, что `~/Downloads` — единственная папка, куда веб может писать сам: посещённая страница способна незаметно скачать туда файл AGENTS.md, а Chrome, Edge и Firefox по умолчанию сохраняют загрузки без подтверждения места. Дальше достаточно, чтобы пользователь сам запустил агента в этой папке — а это, как выяснилось, массовая привычка: только Claude Code совершил более 1300 сессий прямо из `~/Downloads`, сотни клиентов Forever работают так же.

Цифры атаки

Восстановленную цепочку проверили на Codex с безвредной нагрузкой (открыть «Калькулятор») — успех в 90% случаев. Во втором эксперименте вредоносный CLAUDE.md перенаправлял API-трафик Claude Code на сервер атакующего: агент отдавал OAuth-токен, а сервер, выдавая себя за модель, возвращал tool-вызовы — произвольный код выполнялся в 50% попыток. В официальном отчёте researchers подчёркивают: отдельной «уязвимости» нет, это штатное поведение агентов плюс особенности браузеров, и защита ложится на пользователя.

Что делать

Практические правила простые: не запускать кодинг-агентов из `~/Downloads` и других папок, куда что-либо скачивается из веба; работать строго в директории проекта; после случайных запусков вне проекта проверить, не появился ли в папке чужой AGENTS.md/CLAUDE.md, и при подозрении отозвать OAuth-токены агента. Браузеры с подтверждением загрузки (например, Brave) снижают риск, но не снимают его полностью.
