ИИ впервые математически доказал безопасность Signal: DeepMind представила AlphaProof Code

10.11.2026 · по материалам первоисточника
Исследователи Google DeepMind с помощью ИИ-агентов впервые математически доказали ключевые свойства безопасности реального кода протокола Signal — технологии, которая защищает личные переписки миллиардов людей в Signal и Google Messages. Работа, на которую у экспертных команд раньше уходили годы, заняла четыре недели.

Доказательство до последнего байта кода

10 ноября 2026 года Google DeepMind представила AlphaProof Code — агентный фреймворк для формальной верификации ПО. Формальная верификация — это математическое доказательство того, что код работает корректно и без изъянов; высший стандарт гарантии безопасности, который до сих пор был крайне трудоёмким. Результат-презентация — протокол Signal: раньше проверялись только проекты протоколов «на бумаге», а теперь агенты доказали, что скомпилированный код, работающий на устройствах, обеспечивает заявленные свойства — вплоть до защиты сообщений до и после временной компрометации устройства. По заявлению DeepMind, это первый случай, когда ИИ формально верифицировал широко распространённый криптографический протокол на такой глубине, и вообще первый случай формальной верификации реализации такого протокола любым методом.

Как это работало

Схему разделили как исследовательскую команду: люди вместе со смешанной командой моделей переводили цели безопасности Signal в формальные математические спецификации (каждую спецификацию проверял человек), а агенты на Gemini Carbon строили сами доказательства — сгенерировано более 6 миллионов строк на Lean, языке математических доказательств корректности кода. Затем другие агенты аудитовали доказательства и отметили для повторной проверки человеком лишь 1 процент кодовой базы — остальное автоматически проверяет Lean. Весь процесс занял четыре недели вместо лет ручной работы. Для контроля честности системы исследователи вернули в изолированную копию кода Signal два реальных, уже исправленных когда-то бага — и система выдала машинопроверяемое доказательство, что заражённая версия небезопасна.

Что говорит Signal

«Прежняя формальная верификация неизбежно фокусировалась на меньших объёмах, а новый подход даёт значительное расширение. Использовать ИИ-агентов для автоматического перевода живого кода в корректные теоремы Lean — большой прорыв. По мере роста угроз, движимых ИИ, строгая верификация реализации протокола Signal даёт нам ещё большую уверенность, что код выполняет наши обещания о приватности», — заявил Эрен Крет, технический директор Signal.

Зачем это всем остальным

Криптографические протоколы лежат в основе почти всей цифровой коммуникации — от онлайн-банкинга до веб-сёрфинга, и одна ошибка может одновременно затронуть миллионы людей. DeepMind позиционирует AlphaProof Code как способ перенести элитный уровень гарантии безопасности на медицинскую технику, энергосети и критическую инфраструктуру — в паре с защитными агентами вроде CodeMender. Артефакты верификации уже открыты сообществу (google-deepmind.github.io/code-verification), вместе с анонсом опубликована техническая статья.

Практический вывод

Для обычных пользователей Signal и Google Messages ничего менять не нужно: их переписка стала не «проще атакуемой», а математически доказанно защищённой на уровне реализации — таких гарантий до сих пор не имел ни один массовый мессенджер. А для индустрии сигнал прозрачный: дефицит специалистов по формальной верификации, тормозивший её десятилетиями, ИИ-агенты превращают из лет в недели.
