Amazon выпустила AWS Emulator: весь код написал ИИ, люди не вставили ни строки

12.11.2026 · по материалам первоисточника
Amazon представила AWS Emulator — бесплатный локальный эмулятор более 200 сервисов AWS, который, по словам компании, целиком написан автономными ИИ-агентами: ни одной строки кода не написал и не проверил ни один человек.

Эмулятор облака, который построили машины

Amazon выпустила AWS Emulator — бесплатный инструмент, который запускает на обычном компьютере имитацию более 200 сервисов AWS (базы данных, бессерверные функции, хранилища и очереди), причём без подключения к реальной облачной сети. Особая гордость анонса — способ создания: по заявлению Amazon, весь код эмулятора написан тысячами автономных ИИ-агентов. Руководивший проектом инженер Мэттью Голдберг сформулировал это предельно прямо: «Эмулятор полностью написан автономными агентами. Наша команда не написала и не проверила ни одной строки кода».

Как это собрали

Агентов строили в агентной среде разработки Kiro — она превращает текстовое описание требований в спецификации, код и тесты. Работу вели три команды агентов: одни писали тесты, другие искали ошибки, третьи их исправляли; всё это крутилось на платформе Amazon Bedrock AgentCore. Основой послужили более 400 моделей API, описывающих поведение сервисов AWS. Доверие к таким сборкам держат на строгих правилах безопасности, внутри которых агентам вообще разрешено работать.

Но без ложечки дёгтя

Первый публичный релиз оказался живым, как все первые релизы: день спустя на GitHub висело более 70 открытых багов — особенно много нареканий к симуляции базы DynamoDB и бессерверного сервиса Lambda. Главное же замечание разработчиков — эмулятор проверяет права доступа (IAM) мягче, чем настоящий AWS: запрос, который облако бы отвергло, в эмуляторе может пройти. Разработчики ждут от официального продукта уровня хотя бы стороннего LocalStack. При этом те же критики признают: рабочий результат уже в первой публичной версии — обнадёживающий знак.

Почему это важно

Это заметный случай, когда крупная компания выпустила не игрушку, а рабочий инфраструктурный инструмент, созданный агентами без человеческой строки кода в контуре. Amazon ставит эксперимент напоказ: заодно проверяются два вопроса — умеют ли агенты держать качество на объёме целого продукта и меняется ли роль инженера, если код пишут не люди. Ответы пока оба «неоднозначно»: продукт работает, багов вагон, а обсуждение профессии уже идёт — технический директор AWS Вернер Фогельс назвал происходящее изменением самой работы инженера.
