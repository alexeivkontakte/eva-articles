Китайская группа с ИИ-агентом взломала сотни клиентов ConnectWise через облачный бэкап

22.10.2026 · по материалам первоисточника
Атака на цепочку поставок через сервис ConnectWise Cloud Backup затронула почти тысячу Microsoft 365-тенантов. По данным самой ConnectWise, оператором взлома была государственная группа из Китая, которая автоматизировала операцию общедоступным фреймворком ИИ-агентов.

Что произошло

ConnectWise подтвердила несанкционированный доступ к учётным данным приложений своего облачного бэкапа Cloud Backup (бывший SkyKick). Через украденную client assertion для OAuth атакующие входили в Microsoft 365-тенанты клиентов как легитимное приложение — обход MFA и условного доступа сработал «из коробки», потому что мультитенантные приложения Microsoft так не защищаются. Аналитики Huntress зафиксировали первые попытки ещё 13 октября, успешные входы — с 15 октября почти все с одного IP; из проанализированных свыше 10 000 тенантов с установленным ConnectWise подозрительная активность найдена примерно в 1000, а более 300 подтверждённых входов — точное число жертв ConnectWise назвать не может, доступа к средам клиентов у неё нет.

При чём тут ИИ

В официальном уведомлении от 21 октября ConnectWise со ссылкой на трогразведку Microsoft заявила: атаку провела государственная группа из Китая, использовавшая общедоступный фреймворк ИИ-агентов (agentic AI), который автоматизировал и ускорял операцию. В скомпрометированных тенантах часть действий (повышение привилегий, создание точек закрепления) выполнялась автоматически, часть — вручную. Это один из первых публично подтверждённых вендором случаев, когда агентный ИИ назван рабочим инструментом государственной атаки на цепочку поставок. Microsoft подтвердила атаку и сама отключила семь учётных записей приложений; 17 октября ConnectWise централизованно вырубала сервис — только после этого массовые входы прекратились.

Что с данными

Сама ConnectWise утверждает, что бэкапные архивы остались зашифрованными и изолированными, признаков их выгрузки или подмены нет. Восстановление сервиса запущено поэтапно и займёт несколько дней — компания обещает обновления дважды в сутки. Но каждый отдельный тенант всё ещё может содержать несанкционированные изменения и сохранённый доступ атакующих, и проверить это может только админ.

Что делать клиентам

Если в вашем Microsoft 365 когда-либо регистрировалось приложение ConnectWise Cloud Backup или SkyKick — даже если интеграция давно неактивна, но регистрация в тенанте осталась, — проверяйте окружение по официальному техническому руководству ConnectWise (ссылка в первоисточнике) и не включайте соединения до формальных инструкций. Время критично: без расширенного логирования Microsoft удаляет журналы входов Entra ID через 7 дней (максимум 30 дней с лицензией P1/P2), а часть действий атакующих вообще не попадает в логи. Отключайте неиспользуемые зарегистрированные приложения в Entra ID и пересмотрите разрешения мультитенантных приложений — это уязвима архитектура M365 в целом, а не только один вендор.
