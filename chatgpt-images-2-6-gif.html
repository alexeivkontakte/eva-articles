ChatGPT научился делать GIF за один шаг: OpenAI выпустила Images 2.6

05.11.2026 · по материалам первоисточника
OpenAI представила поколение моделей генерации изображений Images 2.6: анимированные GIF теперь создаются за один запрос с покадровым редактированием, генерация стала заметно быстрее, а в API пришли две новые модели с поддержкой SVG.

GIF за один шаг

Главная новинка — анимация. Раньше ChatGPT не умел делать GIF напрямую: пользователи склеивали кадры сторонними инструментами. В Images 2.6 анимированную картинку можно попросить одним текстовым сообщением — например, «нарисуй танцующего кота», — и чат-бот сразу выдаёт GIF с настройками скорости воспроизведения. Готовую анимацию можно править прямо в чате: просмотреть отдельные кадры, поправить конкретный кадр, изменить темп, а затем поделиться результатом.

Быстрее, и с новыми форматами

OpenAI сообщает, что обновлённая генерация работает заметно быстрее: пользователи ChatGPT и API создают уже более 4 млрд изображений в неделю против прежних 3 млрд. Для разработчиков в API выходят две новые модели — по анонсу компании, примерно на 50% быстрее предыдущих, — с новыми элементами управления и поддержкой SVG наряду с GIF. Обновление разворачивается для всех тарифов ChatGPT, в веб-версии, мобильных приложениях, Codex и API. В официальном анонсе компания также упоминает «более точное редактирование» и работу с референсными изображениями.

Контекст

Битва за «креаторов» между генераторами картинок идёт третий год: Google, Adobe и Midjourney давно продают анимацию и редактирование как отдельные продукты, а теперь всё это сжимаётся до одного сообщения в чат-боте. Отдельного официального анонза российского аналога такого уровня (поколение модели с нативными GIF в массовом чат-боте) нет; ближе всего открытые веса Kandinsky Avatar, которые «Сбер» выложил в конце октября, — но это другая ниша, говорящие аватары.
