Claude сама написала пять рабочих эксплойтов: от обхода блокировки Android до root на Linux-сервере за 53 минуты

29.10.2026 · по материалам первоисточника
Anthropic опубликовала исследование Frontier Red Team: её внутренняя модель Claude нашла и превратила в рабочие цепочки атак уязвимости в Chrome, Safari, Android, Windows и Linux. Самая опасная — нулевое взаимодействие с жертвой: атакующий получает root на Linux-сервере по сети, просто отправляя пакеты.

Пять цепочек, собранных почти без человека

Команда Anthropic Frontier Red Team несколько месяцев использовала не выпускавшуюся внутреннюю модель для поиска уязвимостей в самом массовом и критичном софте. Результат — пять законченных цепочек атак с удалённым выполнением кода, описанных в официальном исследовании «Discovering and exploiting vulnerabilities in critical, real-world software with Claude». Каждая находка передана вендорам по правилам координированного раскрытия (90 дней на патч плюс 45 дней до подробностей).

Браузеры и телефон

В Chrome Claude нашла дыру в движке V8, песочницу памяти, гонку в CacheStorage и use-after-free в FedCM — вместе это даёт запуск произвольного кода вне песочницы браузера буквально через несколько секунд после открытия страницы. Google закрыла вопросы в Chrome 156: всего по материалам Anthropic назначено 62 CVE, из них 13 выходов из песочницы и 21 уязвимость для компрометации рендерера. В Safari цепочка оказалась «только для данных»: без выполнения кода модель обошла политики одного источника и получила доступ к истории, cookie и чужим сессиям — Apple выпустила исправление в тот же день. Для Android на реальном Pixel 9 Claude объединила три слабости протокола USB-сопряжения и выкачивала фото с заблокированного телефона; Google уязвимость закрыла.

53 минуты до root без единого клика

Самая серьёзная демонстрация — ядро Linux. В сетевом стеке multipath TCP модель нашла гонку, приводящую к use-after-free: удалённый атакующий без учётных данных сначала раскрывает раскладку памяти ядра (48 минут), затем перехватывает управление и выполняет команду с правами root (ещё 5 минут). Проигрыш гонки не роняет систему — можно пробовать бесконечно. Уязвимость получила CVE-2026-98432 и уже исправлена в апстриме и всех поддерживаемых ветках stable. Для Windows Claude написала удалённый отказ сервиса HTTP/3-серверов — без выполнения кода.

Что это значит для защитников

Anthropic подчёркивает: многошаговые эксплойты, доступные раньше лишь узким командам специалистов, теперь моделируют ИИ почти без человеческой помощи — и доказывают это рабочим кодом. Компания советует защитникам начинать сканировать собственный код и получила расширенный доступ к программе Cyber Verification Program. Ранее той же командой был проверен 21-годичный open-source проект и 25 крупных репозиториев, где модель нашла около 500 дефектов безопасности.
