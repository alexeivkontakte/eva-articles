Наделла признал: Claude Code за полгода подорвал десятилетие VS Code. «Это то, что нас зацепило»

23.11.2026 · по материалам первоисточника
Гендиректор Microsoft Сатья Наделла в интервью The Pragmatic Engineer признал: выход Claude Code от Anthropic всего за полгода подорвал десятилетие VS Code. Разработчики стали реже открывать редактор, а Microsoft пришлось срочно превращать VS Code в хаб для ИИ-агентов.

«Шесть месяцев — и IDE померкла»

В большом интервью подкасту The Pragmatic Engineer (вышло 16 ноября 2026 года) глава Microsoft Сатья Наделла честно разобрал, почему GitHub Copilot проиграл гонку Claude Code. По его словам, после появления агента от Anthropic классическая среда разработки «поблекла» буквально за полгода — хотя VS Code десять лет держался на вершине инструментов программиста. Часть разработчиков, по наблюдениям СМИ, и вовсе перестала открывать редактор: код рождается в диалоге с агентом.

Ставка на «хаб агентов»

Наделла назвал это «тем, что нас зацепило» (the thing that hit us): у Microsoft уже были Copilot и VS Code, но ответ на агентский формат оказался неготовым. Теперь компания перестраивает VS Code в хаб для ИИ-кодинг-агентов — чтобы редактор стал не местом, где печатают код, а диспетчерской, где им управляют. Вторая мысль интервью: писать код стало дёшево, а вот проверять, что он работает, — по-прежнему трудно и дорого. Отдельно топ-менеджер высказался против тезиса «ИИ убьёт программирование»: чем дешевле код, тем важнее инженеры, которые отвечают за надёжность.

Почему это важно

Признание первого лица весит больше любого обзора: Microsoft владеет и VS Code, и GitHub Copilot, и одновременно пропускает в этот рынок партнёра — Anthropic. Полгода, за которые агент съел целую категорию инструментов, — самый наглядный сигнал того, как быстро ИИ-агенты перекраивают рынок разработки. Отдельного официального анонса на блогах Microsoft по этой теме нет: слова прозвучали именно в интервью.

И это не единственная фронт-линия: за последние недели редакторы уже ловили в экосистеме расширений Claude Code SSH-бэкдор, а агентов — в сливе паролей через собственные конфиги. Инструмент растёт быстрее, чем безопасность вокруг него.
