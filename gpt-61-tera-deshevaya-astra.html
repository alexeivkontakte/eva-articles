OpenAI выпустила GPT-6.1 Terra: уровень флагмана Astra за десятую часть цены

27.10.2026 · по материалам первоисточника
OpenAI представила GPT-6.1 Terra — быструю модель для офисных задач и работы с компьютером. Цены в API срезаны вдвое, а по внутренним тестам Terra идёт вровень с флагманской Astra при десятой части стоимости токена. Все бенчмарки — данные самой OpenAI.

Что такое Terra

OpenAI выпустила GPT-6.1 Terra — «среднюю» модель семейства GPT-6, заточенную под повседневную агентскую работу: разбор изображений и чертежей, точное управление интерфейсами программ, заполнение форм, составление коммерческих предложений и даже монтаж видео. Модель уже доступна подписчикам Plus, Pro, Enterprise и Edu в ChatGPT Work и Codex, а разработчикам — в API под именем gpt-6.1-terra. Свежий лог GitHub подтверждает: Terra сразу зашла в GitHub Copilot для агентского кодинга и работы в терминале.

Цены

Ставки в API на 50% ниже, чем у GPT-5.6 Terra и GPT-6.1 Sol: 1 доллар за миллион входных токенов, 0,05 доллара за миллион кэшированных и 5 долларов за миллион выходных. По словам OpenAI, по уровню агента Terra идёт рядом с флагманской Astra примерно за десятую часть цены за токен, а задачи выполняет более чем втрое быстрее Astra и Sol.

Бенчмарки

В тесте Agents' Last Exam, где ИИ-агенты решают профессиональные задачи в реальных программах, Terra при среднем уровне рассуждений набрала на 15 процентных пунктов больше предшественницы GPT-5.6 Terra примерно за треть её цены. Во внутреннем тесте на частоту ошибок доля сбоев при низком уровне рассуждений упала с 53,6% до 16,7%, а при максимальном — до 4,3%. В Terminal-Bench 4.0 на максимальных настройках модель закрыла 50,3% задач против 21,5% у предшественницы. Важно: все эти цифры приводит сама OpenAI, независимых проверок пока нет.

Безопасность

По собственной системе оценки рисков OpenAI отнесла Terra к критическому уровню в кибербезопасности и к высокому — по биохимическим рискам, сохранив для неё защитные меры флагманской Astra. Для агентских рантаймов это лишний reminder: модель, которая сама кликает по интерфейсам и работает в терминале, — тот же вектор риска, что и флагман, даже если стоит вдесятеро дешевле.
