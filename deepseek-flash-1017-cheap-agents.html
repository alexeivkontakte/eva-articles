DeepSeek выпустила Flash-1017: дешёвая агентная модель бьёт флагманов на их поле

17.10.2026 · по материалам первоисточника
17 октября DeepSeek выпустила DeepSeek-V4.1-Flash-1017: ~16 млрд активных параметров, окно 1 млн токенов, MIT-лицензия. Компания заявляет превосходство над Claude Opus 5 в четырёх агентских бенчмарках при стоимости задачи $0,10–0,20 — меньше десятой части американских флагманов.

Компания DeepSeek выпустила DeepSeek-V4.1-Flash-1017 — обновление лёгкой модели V4.1 Flash. Дата-релиз 17 октября 2026 года: модель уже доступна на сайте, в приложении и через API под именем `deepseek-flash`, а веса опубликованы под лицензией MIT.

Цифры из карточки модели

По официальной карточке на Hugging Face — 763 млрд суммарных параметров (активных, по данным СМИ, около 16 млрд), окно контекста 1 млн токенов. В агентских тестах DeepSeek приводит модель выше Claude Opus 5: DeepSWE v1.1 — 77,0 против 74,0; Automation-Bench — 60,5 против 50,3; Agents' Last Exam — 35,4 против 28,6; Apex Bench — 72,1 против 65,8. На общем рассуждении (HLE — 42,6 против 56,3) и Terminal-Bench (42,3 против 51,8) Opus пока впереди.

Цена: десятая часть флагманов

Ключевой аргумент — стоимость выполнения задач: примерно $0,10–0,20 на задачу, меньше десятой части американских флагманов. Модель сокращает время выполнения заданий и длину ответа — меньше токенов на результат, тот же бюджет. DeepSeek называет это движением вдоль границы Парето «качество — цена» сразу в нескольких агентских обвязках.

Поиск — собственный

Вместе с моделью компания открыла Search/Fetch API на «собственном поисковом движке»: веб-поиск и загрузка страниц прямо из API, $0,75 за тысячу вызовов с 31 октября. Заявление о собственной поисковой инфраструктуре часть обозревателей пока считает спорной — независимых подтверждений мало.

Локальный запуск

Веса под MIT можно скачать и запускать у себя: сообщество уже обсуждает запуск на одноплатных серверах класса NVIDIA DGX Spark. Для продуктовых команд это ещё один аргумент в пользу схемы «агент-флагман планирует — дешёвая модель исполнитель», где бюджет на рутинные вызовы падает на порядок.
