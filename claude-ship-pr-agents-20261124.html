Anthropic запустила Claude Ship: Claude теперь сам ревьюит pull request, чинит падения CI и одобряет рутину

23.11.2026 · по материалам первоисточника
Anthropic представила Claude Ship: агенты PR Steward и Claude Approvals в бете сами разбирают замечания ревью, пушат фиксы к упавшим проверкам и одобряют рутинные изменения по политике организации. Слияние всё ещё за человеком.

Anthropic представила Claude Ship — продукт, в котором Claude берёт на себя целый участок работы с pull request: review, исправление замечаний и даже одобрение рутинных изменений. Анонс состоялся 23 ноября 2026 года, внутри две новые бета-новинки — агенты PR Steward и Claude Approvals. Сам merge по-прежнему остаётся за человеком.

Работает это так: уже знакомый режим Code Review (анонсирован в марте, общая доступность в октябре) находит баги в PR, а новый PR Steward подхватывает упавшие CI-проверки, конфликты слияния и комментарии ревьюеров — правит код, пушит фиксы и оставляет комментарии о том, что именно изменил. Claude Approvals умеет одобрять рутинные изменения, если это разрешено политикой организации: агент учитывает выводы Code Review и собственные классификаторы команды, заданные обычным языком.

В Claude Code появились команды /ship и /steward: первая открывает pull request, прогоняет ревью и запускает «наблюдение» за ним до состояния готовности, вторая начинает то же наблюдение без повторного ревью. Корпоративный Claude Ship обслуживает целые репозитории и тарифицируется на уровень организации. Продукт доступен клиентам тарифов Claude Team и Enterprise и работает с репозиториями на GitHub.

Логика Anthropic понятна: ревью и починка падений CI — самая рутинная часть работы инженера, и её уже отдают агентам. Показательно, что даже Microsoft признаёт: Claude Code за полгода заметно потеснил VS Code — теперь гонка идёт за весь цикл разработки, а не только за генерацию кода.
